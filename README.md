# 遥汐 · AeluraTool

面向 Windows 的桌面工具箱。按用途浏览工具，在首页统一搜索，或使用可自定义的快捷键快速打开。

## 下载与安装

前往 [Releases](https://github.com/tomh500/AeluraTool/releases) 查看版本。Nightly 为自动构建的测试版。

支持 Windows x64，需要应用包身份，不能单独复制 EXE 运行。当前 nightly ZIP 包含未签名 MSIX 和依赖，需经发布者签名后才能安装。已签名分发包按包内说明安装，保留依赖目录和安装脚本。

## 功能

| 工具 | 用途 |
| --- | --- |
| 快捷文件检索 | 查找本地文件，打开、定位、复制路径和管理文件 |
| 截图与标注 | 区域或窗口截图、编辑、复制分享、最近截图 |
| 录屏与即时重放 | 录制屏幕或窗口、采集声音、保存近期重放；默认 Ctrl+Alt+Shift+F 保存重放 |
| 文件哈希校验 | 计算 SHA-256、核对摘要、比较两个文件 |
| IPv6 综合工具 | 检查网卡、系统开关、地址、路由、DNS 和 IPv6 公网连通性，提供启用与恢复，以及高级诊断工具 |
| 网络测速 | 分别测量 IPv4 / IPv6 的真实下载、上传单连接吞吐，可选择测试流量并取消 |
| DNS 查询 | 查询 A / AAAA 地址、TTL 和解析状态 |
| TCP 端口检测 | 检测指定端口的 IPv4 / IPv6 连接与握手耗时 |
| 文件迁移 | 移动文件或目录后保留原路径访问，支持进度和取消 |
| StrikeSense | 从游戏分类打开独立的游戏工具 |

## 开始使用

在顶部搜索工具名称，或从分类选择工具。默认 Ctrl+Alt+F 呼出检索浮窗；方向键选择，Enter 打开，Ctrl+Enter 定位，Esc 隐藏。快捷键可在设置中搜索、修改和停用；占用或保存失败保留原配置。

内置检索首次使用需要建立索引，不读取文件正文。支持路径、大小写、全字和正则选项，显示前 200 项及匹配总数。也可选择连接本机已运行的 Everything。

设置支持跟随系统、浅色和深色主题，中英文即时切换，以及启动动画、托盘和登录自启动选项。中文系统默认中文，其他系统默认英语。部分操作需要管理员授权。

网络测速直连 speed.cloudflare.com，不使用系统 HTTP 代理，VPN 路由仍可能生效。每个方向可选择 1、10 或 50 MB；双协议下载与上传全部测试约消耗 4、40 或 200 MB，另有协议开销。结果反映到该服务器的单连接有效吞吐，包含连接与服务器响应耗时，不等同于宽带上限。网络工具的快捷键默认关闭，可到快捷键页面启用。

## 文件迁移与恢复

迁移前关闭使用原文件的程序。不能覆盖目标，不能迁移系统关键目录、网络路径或重解析点。文件符号链接需要开发者模式或管理员权限。跨盘先复制并校验，再完成原路径链接。文件任务期间暂不允许退出。

若操作中断，保留原件父目录中的 .aelura-recovery-*.txt，按记录核对原件、目标、备份和暂存副本。目前恢复需要人工核对，请勿删除唯一副本。
