# 账号登录

客户端账号功能在设置页中，支持全局搜索“账号 / QQ / Google”。本地工具功能无需登录；账号状态只用于远端服务。登录按钮仅在服务端已配置对应提供方时启用。服务地址默认留空，未配置时不发起网络请求；不会自动填写 SSH 联调地址。用户明确保存的地址仍会保留，可清空后保存以取消配置。

首次使用通过系统浏览器完成 QQ 授权，再于十分钟内绑定 Google。后续使用已绑定 Google 登录同一账号。绑定要求分别验证两边的控制权；不会根据 QQ 号码、邮箱、昵称或头像合并账号。服务访问权限由服务器另行批准，不会因为登录成功自动获得。

客户端只保存本系统会话，使用 Windows 凭据管理器按服务根地址隔离；不保存 Google/QQ 密码或令牌。服务地址保存于现有配置的 Account/Service 字段，只接受 HTTPS；本机联调允许 localhost HTTP。保存失败保留旧地址，凭据写入失败保留旧会话。网络请求在后台执行，页面提供等待状态与取消；取消不回退已经完成的服务器绑定。

独立后端位于 `C:/Users/jingy/source/repos/WallpaperRelay`，使用 MySQL 存储用户、绑定关系与会话。服务端源码、数据库密码和 OAuth 密钥不放入 Win32 工程。客户端协议与应用注册说明见后端 ACCOUNTS.md。

当前没有 QQ 互联或 Google OAuth 应用凭据，真实授权待注册后联调。客户端没有假登录或跳过验证的入口。首次联调通过 SSH 转发服务器 127.0.0.1:18741 到 Windows 同一端口，再在设置页刷新账号状态；QQ 的正式回调需要满足 QQ 互联的主域名审核要求。
