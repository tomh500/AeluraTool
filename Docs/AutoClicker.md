# AutoClicker

从游戏分类或统一搜索打开工具子界面。开关控制使能状态；停用时编辑触发键、输出键、每秒次数和间隔随机幅度。启动默认停用，参数保存在用户配置中。

快捷键直接切换启停，不打开主窗口；默认 Ctrl+Alt+C，统一在快捷键页面修改，工具页的“管理快捷键”只跳转并筛选该页面。尊重已有绑定和启停设置，注册占用或保存失败保留旧绑定。设置中的“快捷键操作提示”统一控制所有快捷键的桌面提示，关闭提示不影响操作执行。AutoClicker 显示实际启停状态，其他快捷键显示操作已触发，不将触发提示冒充任务完成。

长按触发键开始输出，松开停止；Esc 紧急停用。工具箱自身获得焦点时不捕获触发键，以便使用鼠标操作开关；切换前台窗口清除长按状态，需要重新按下触发键。当前按键会在停用、松开或切换窗口时尝试配对释放；系统输入权限限制仍可能阻止发送。

## 输入与提示参考

用户指定的 DearM16A4 使用扫描码键盘输入、分开的按下/松开事件、15–24 毫秒按住时间以及样本间隔加扰动，并非驱动接口。本项目按相同行为重新实现状态机，样本归一化后按用户速率与随机幅度缩放，高速时缩短按住时间以留出松开间隔。原始数值与来源记录位于 Tools/DearM16A4。没有从开发机绝对路径加载外部程序。

通过本机 Everything SDK 查询找到 LiquidBounce 项目，读取其 src-theme/src/routes/hud/elements/notifications 下的提示实现作为交互参考：启停图标、状态标题、模块名、约三秒消失、同模块快速重复切换替换旧提示。这里独立实现原生 WinUI 通知，没有复制 Svelte/CSS/SVG 代码或资产，也未修改该项目。提示不激活窗口，使用主题资源并遵循系统动画设置；独占全屏游戏不保证可见。

## 启动方式

此应用需要包身份和包依赖图。请从桌面快捷方式或开始菜单启动，不要直接运行构建目录下的 EXE。直接启动可能在 Windows App SDK 的静态初始化阶段失败，早于应用异常处理执行，Debug CRT 会显示 abort 对话框。桌面快捷方式使用 shell:AppsFolder 包激活入口。
