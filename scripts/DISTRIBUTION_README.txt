遥汐 / AeluraTool — Windows x64

安装：
1. 将整个 ZIP 解压到本地目录。
2. 本包使用本地自签名证书，首次安装需由接收者核对来源并信任随附的 AeluraTool.cer。
3. 右键 Add-AppDevPackage.ps1，使用 PowerShell 运行，按安装脚本的提示安装证书、依赖和应用；证书安装步骤可能需要管理员权限。
4. 安装后从开始菜单打开遥汐。开机自启动时始终进入托盘；手动打开显示主窗口。从托盘图标或再次打开应用可恢复窗口。

也可先将证书手动导入本地计算机的“受信任人”，安装 Dependencies\x64 中缺少的框架包，再双击 MSIX。
不要关闭系统签名检查或关闭安全软件来安装本包。不要单独复制 EXE 运行。

关闭窗口可选择退出或到托盘，并能记住选择；在设置中修改。托盘右键可以打开主窗口或退出。
开机自启动默认关闭，可在应用设置中启用；若已被 Windows 禁用，需要在系统的启动应用设置中启用。

本包包含签名 MSIX、公开证书和运行依赖，不含签名私钥。
自签名仅用于当前测试分发。正式公开发布应改用接收设备信任的代码签名或 Microsoft Store。
包的签名不代表第三方源码或图片已取得公开再分发授权；详见 BUILD_AND_DISTRIBUTE.md 与 Licenses。
未在干净设备上验证安装；最低系统条件以包清单与所附运行库要求为准。建议在受支持的 Windows 11 x64 上先测试。
